# PredictorAI-Capital

Motor de análisis financiero e inmobiliario enfocado en la evaluación cuantitativa de bienes raíces y proyectos de inversión.

## Descripción

PredictorAI-Capital es un sistema desarrollado en Python para automatizar el cálculo de métricas financieras clave en el sector inmobiliario. Su objetivo principal es procesar variables de ingresos, costos operativos y estructura de capital para facilitar la toma de decisiones basada en datos.

## Stack Tecnológico

* Lenguaje de programación: Python 3.x
* Control de versiones: Git / GitHub

## Funcionalidades (Versión 0.1.0)

* Lógica base para el cálculo de indicadores de rendimiento financiero (Cap Rate, flujo de caja e ingresos netos).
* Interfaz en consola para la captura interactiva de parámetros por inmueble.
* Arquitectura modular preparada para refactorización hacia arquitectura orientada a objetos (POO) e integración futura con APIs.
